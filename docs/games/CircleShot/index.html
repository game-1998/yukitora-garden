サークルショット

画面上のプレイヤー(●)を 操作し、迫ってくる敵や弾を避けながら敵を倒すだけのシンプルなシューティングゲームです。
敵を倒したときにランダムに出現するアイテムを取ると、ショットの種類や連射スピード、 スコア倍率が変化し、状況に応じた戦い方が求められます。
アイテムを使いこなしハイスコアを目指しましょう!!

※基本スコア：敵にショットを当てる ⇒ 10Pt
敵を倒す ⇒ 倒した敵HP分のPt
(1/3)

アイテム種類

正面と斜め前方の3方向同時ショットに変わる
正面のみのシングルショット（通常）に戻る
ショットの連射がスピードが上がる
（上限：ゲーム開始時から1段階UP）
ショットの連射スピードが下がる
（下限：ゲーム開始時から1段階DOWN）
得られるスコアが今の2倍になる
（上限：基本スコアの2倍）
得られるスコアが今の半分になる
（下限：基本スコアの半分）
(2/3)
